Serverest Aula 1

Sobre o projeto

Este repositório contém a Collection do Postman utilizada na atividade de consumo de uma API REST com a Serverest.
Requisições realizadas

- Cadastro de usuário
- Login de usuário
- Cadastro de produto
- Consulta de produto
- Teste de cenário inválido
Tecnologias utilizadas

- Postman
- API REST Serverest
- GitHub
Objetivo

Praticar o envio de requisições HTTP, autenticação, cadastro e consulta de dados utilizando uma API REST através do Postman.
